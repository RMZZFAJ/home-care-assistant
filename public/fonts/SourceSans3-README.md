# Source Sans 3

Regular, Semibold and Bold are unmodified TTF files from the
[official Adobe repository](https://github.com/adobe-fonts/source-sans/tree/87b37a2daaed80fcb8e8ccb0085c4d72ddade12e).
Commit: `87b37a2daaed80fcb8e8ccb0085c4d72ddade12e`.

The SIL Open Font License is included in SourceSans3-LICENSE.txt. These embedded
fonts serve the approved PDF composition. Existing Noto Sans files remain for
historical document renderers.
