# Contratos Meta locais

JSONs de templates/Flows são referências locais consumidas por ferramentas.
Seus caminhos foram mantidos. Não comprovam aprovação, publicação,
persistência
do editor, entrega ou callbacks reais. DEC-019 mantém ativação Meta/Flows
diferida; [integrações atuais](../current/WHATSAPP_AI.md) qualificam as
limitações.

Não executar scripts de submissão como consulta com token herdado. A separação
inspect/submit e homologação pertencem a D0/D7 autorizados. Nenhum JSON de
contrato, provedor ou configuração foi alterado nesta C.
